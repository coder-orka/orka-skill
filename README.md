# Orka Niulai Image

将人物、宠物、动物或物体照片转换为保留原主体特征的可爱牛系毛绒 3D 图片。

默认特征：

- 动物主体整体使用短密绒面、柔软填充和少量布偶接缝；
- 保留脸型、眼睛颜色、毛色分区、姿势、构图与场景；
- 将清晰可见的原耳一对一替换为唯一一对圆润牛耳；
- 添加一对小牛角，并在胸口可见时添加一枚铃铛；
- 排除毛线、针织、钩织和编织线圈质感。

## 安装

将仓库克隆到 Codex Skills 目录：

```bash
git clone https://github.com/coder-orka/orka-skill.git ~/.codex/skills/orka-niulai-image
```

## 使用

```text
使用 $orka-niulai-image 保留照片主体与场景，生成可爱牛系毛绒 3D 图片。
```
